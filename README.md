O **Chat2Order** é um ecossistema completo de software desenvolvido para resolver um problema operacional crítico: a gestão de pedidos descentralizados em conversas de aplicativos de mensagens. Através da integração de Inteligência Artificial, o ecossistema captura, estrutura e direciona dados brutos diretamente para a operação de ponta, eliminando processos manuais e falhas de comunicação.

Este repositório engloba os três pilares principais da solução: a **Plataforma Core**, a **Extensão de Captura** e a **Landing Page de Alta Conversão**.

## 🛠️ Arquitetura do Ecossistema

O ecossistema foi desenhado de forma modular, onde cada componente desempenha um papel estratégico na jornada dos dados:

1. **Plataforma Core (Backend, IA & Banco de Dados):** Centraliza as regras de negócio, gerencia o processamento de linguagem natural (NLP) via Inteligência Artificial e armazena os pedidos estruturados prontos para consumo operacional.
2. **Extensão para Google Chrome:** Atua diretamente no ecossistema do cliente (WhatsApp Web), agindo como o agente de captura não intrusivo que extrai o histórico relevante da conversa sem fricção para o operador.
3. **Landing Page de Alta Performance:** O ponto de contato público do produto. Focada estritamente em **comunicação de valor** e conversão, construída do zero sem o uso de construtores visuais ou templates prontos.

---

## 🚀 Tecnologias Utilizadas

A stack foi selecionada para garantir máxima performance, tipagem estática segura, estilização preditiva e build em tempo real:

* **Frontend:** [React](https://reactjs.org/) — Arquitetura baseada em componentes reutilizáveis e reatividade eficiente.
* **Tipagem:** [TypeScript](https://www.typescriptlang.org/) — Segurança em tempo de compilação, interfaces robustas para os contratos da IA e contratos de API.
* **Build Tool:** [Vite](https://vitejs.dev/) — HMR (Hot Module Replacement) extremamente rápido e pipeline de build otimizado.
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/) — Utility-first framework focado em consistência de design system e responsividade nativa.
* **Animações (Landing Page):** Framer Motion / CSS Transitions nativos para implementação de Motion Design premium.

## 🎨 O Desafio da Landing Page: Design de Alto Nível

Enquanto a plataforma resolve a complexidade técnica e a dor operacional, a Landing Page foi tratada como um desafio de **engenharia de design** e posicionamento de produto. 

Inspirada por padrões visuais estabelecidos por gigantes de tecnologia globais como **Stripe, Linear e Vercel**, a página foi codificada do zero aplicando conceitos avançados de:
* **Estrutura de Conversão:** Fluxo de leitura planejado para guiar o lead até a tomada de ação.
* **Performance Impecável:** Carregamento ultra rápido medido por Core Web Vitals elevados, essencial para SEO e anúncios.
* **Hierarquia Visual & Motion Design:** Transições sutis e microinterações que elevam a percepção de valor do produto de software.
* **Responsividade Extrema:** Adaptação fluida para qualquer tamanho de tela sem quebras de layout.
